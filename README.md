### 1. Анализ данных о факторах успеваемости студентов
Датасет: StudentPerformanceFactors.csv

Источник: https://www.kaggle.com/datasets/lainguyn123/student-performance-factors/code

**Цель:** проведение описательного анализа переменных

**Содержание исследования:** 
   - постановка задачи 
   - анализ описательных статистик количественных переменных
   - поиск взаимосвязей между переменными с помощью таблиц, точечных диаграмм, корреляционной матрицы
   - анализ распределений значений переменных с помощью гистограмм и круговых диаграмм, выявление признаков с асимметрией
   - сравнение показателей студентов (мотивации, результатов) в зависимости от различных факторов (качества приподавания6 влияния родителей и сверстников и т.д.)

### 2. Статистические тесты
Датасет: Worldbank.xlsx

Источник данных: Worldbank Data. Датасет предоставлен преподавателем.

**Цель:** проверить на наличие статистически значимых различий между группами стран (по доходу, уровню развития экономики) в экспорте и импорте отдельных категорий товаров или услуг

**Содержание исследования:**
- проверка нормальности распределений с помощью статистических тестов Колмогорова-Смирнова или Шапиро-Вилка и визуализаций
- проведение теста хи-квадрат категориальных переменных и визуализации с помощью таблиц сопряженности и столбчатых диаграмм
- проведение корреляционного анализа: построение диаграмм рассеивания, подбор подходящего коэффициента, их проверка на статистическую значимость
- расчет парного коэффициента корреляции
- проверка на наличие статистически значимых различий переменных между группами, подбор параметрического или непараметрического тестов, формулирование гипотез

### 3. Кластерный анализ стран
Датасет: WIPO-GII_2022.xlsx

Источник данных: Worldbank Data. Датасет предоставлен преподавателем.

**Цель:** провести разделение на кластеры стран по группе признаков

**Содержание исследования:**
- выбор 14 переменных для дальнейшего анализа
- проведение факторного анализа, выделение 3 компонент
- проверка на корреляции между переменными и формирование итогового списка для кластерного анализа
- кластеризация 3 методами: иерархический, k-средних, DBSCAN
- описание профиля кластеров
- проведение апостериорного анализа кластеров: проверка на статистически значимые различия средних значений переменных по кластерам 1) тестом ANOVA, 2) апостериорным тестом Тьюки для попарного сравнения
- анализ содержания кластеров: по уровню дохода, развития экономики, по регионам

### 4. Регрессионный анализ успеваемости студентов
Датасет: StudentPerformanceFactors.csv

Источник: https://www.kaggle.com/datasets/lainguyn123/student-performance-factors/code

**Цель:** выявить факторы, влияющие на успеваемость студентов (на результат экзамена)

**Содержание исследования:**

Зависимая переменная - Exam_Score (результат экзамена)
- выбор метрических и категориальных предикторов
- проверка корреляции метрических предикторов с зависимой переменной и выбор предикторов с наиболее высокой корреляцией с зависимой переменной
- проверка уровня корреляции между предикторами, исключение предикторов с высокой парной корреляцией
- оценка характера взаимосвязи предикторов и зависимой переменной с помощью визуализаций (диаграмм рассеивания, таблиц сопряженности, ящиков с усами)
- формулирование гипотез о влиянии предикторов на зависимую переменную
- преобразование категориальных признаков в дамми-переменные
- построение модели множественной линейной регрессии, модели со стандартизированными коэффициентами и их оценка
- интерпретация коэффициентов модели (и проверка гипотез исследования)
- проверка на наличие гетероскедастичности, мультиколлинеарности, выбросов, влияющих наблюдений
- удаление выбросов и построение новой модели, сравнение с предыдущей

### 5. Бинарная логистическая регрессия для оценки вероятности выгибания на работе академических работников
Датасет: burnout.xlsx

**Цель:** выявить факторы, влияющие на повышение вероятности эмоционального выгорали на работе

**Содержание исследования:**
- формулирование гипотез исследования
- выбор предикторов
- рассмотрение взаимосвязей между предикторами и зависимой переменной burnout (с помощью столбчатых диаграмм и диаграмм рассеивания)
- преобразование категориальных признаков в дамми-переменные
- построение модели
- оценка статистической значимости и предсказательной силы модели (матрица ошибок)
- расчет метрик accuracy, specificity, recall/ sеnsivity, precision, F1-score, FPR (False Positive Rate)
- анализ ROC-кривой
- оценка значимости коэффициентов бинарной регрессии
- интерпретация коэффициентов модели (и проверка гипотез исследования)
- проверка на наличие мультиколлинеарности, выбросов, влияющих наблюдений
- проверка на нормальность остатков модели
- удаление выбросов и построение новой модели

### 6. Построение моделей панельных данных
Датасеты: Worldbank_panel.xlsx, World_Development_Indicators-2.xlsx

Источник: Worldbank Data. Первый датасет предоставлен преподавателем, второй - собран самостоятельно.

**Цель:** выявить факторы, влияющие на уровень экспорта высокотехнологичной продукции

В качестве зависимой переменной мной выбран показатель экспорта высокотехнологичной продукции. 

**Содержание исследования:**
- выбор предикторов и проверка на отсутствие высокой парной корреляции
- описательный анализ зависимой переменной и предикторов, их динамика во времени
- формулирование гипотез исследования
- построение объединённой модели панельных данных (Pooled model), модели с фиксированными эффектами (Fixed effects model) и модели со случайными эффектами
- сравнение обычной МНК (Pooled model) и модели со случайными эффектами тестом Бреуша-Пагана -> вывод о наличии индивидуальных эффектов 
- выбор между моделью с фиксированными эффектами или моделью со случайными эффектами тестом Хаусмана -> выбор модели с фиксированными эффектами
- оценка статистической значимости коэффициентов регрессии
- интерпретация коэффициентов модели и проверка гипотез исследования
